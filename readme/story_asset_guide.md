# 비주얼노벨 스토리 작업 기준서
이 문서는 현재 프로젝트 파일(`game.zip`) 안에 실제로 존재하는 리소스를 기준으로, 이후 스토리/연출/씬 집필 시 일관성을 유지하기 위한 작업 기준서다.
## 1. 절대 기준
- 새 캐릭터를 임의로 추가하지 않는다.
- 현재 존재하는 이미지, CG, 배경, 오디오 범위 안에서 연출을 우선 구성한다.
- 분위기는 초중반에 캐릭터 정과 일상 호흡을 쌓고, 불안 요소는 너무 이르게 과하게 드러내지 않는다.
- 스토리를 쓸 때는 `script.rpy`에 이미 있는 씬 흐름과 타이틀을 우선 존중한다.

## 8. 현재 스토리 톤 가이드
- 학교 생활, 준비 작업, 방과 후 시간, 함께 걷는 길, 팀 과제 같은 일상적 접점이 핵심이다.
- 캐릭터 호감도는 큰 사건보다도 작은 농담, 부탁, 답례, 같이 보내는 시간으로 쌓는다.
- 장면 분위기는 씬 20대 중반 전까지는 지나치게 무겁게 내리지 않고, 약한 불안감이나 떡밥만 가장자리에서 관리한다.
- 유나는 활기/장난기, 하린은 단정/예민함, 설아는 차분함, 가은은 부드러움/섬세함 쪽으로 기본 인상을 유지한다.
## 9. 이후 스토리 작성 규칙
- 새 장면을 쓸 때는 먼저 **배경**, **등장인물**, **사용 가능한 표정**, **어울리는 BGM/SFX**를 이 문서 안에서 고른 뒤 집필한다.
- CG는 감정 고조나 기억에 남는 순간에만 사용하고, 일상 장면은 스탠딩+배경 중심으로 운용한다.
- 존재하지 않는 복장/소품/장소를 핵심 연출로 잡지 않는다. 필요하면 현재 배경에서 설명 가능한 범위로 처리한다.
- 리소스 이름과 분위기가 맞지 않는 연출은 피한다. 예: `bgm_trauma_*` 계열은 초반 평화 장면에 남용하지 않는다.
## 10. 스토리 작성 전에 확인할 체크리스트
- 이 장면에 실제로 있는 캐릭터만 등장하는가?
- 현재 보유한 표정으로 감정 표현이 가능한가?
- 배경과 시간대가 기존 흐름에 맞는가?
- 오디오 분위기가 장면 감정선과 맞는가?
- 초중반의 따뜻한 축적 톤을 깨지 않는가?
## 11. 추천 사용 방식
새 씬을 요청할 때 아래 형식으로 작업하면 일관성이 유지된다.

```md
[씬 번호]
[장소/배경]
[등장인물]
[기본 분위기]
[사용할 표정 후보]
[어울리는 bgm/sfx]
[긴 효과음도 있기에 필요한거 나오고 바로 끊기 그리고 피치나 속도를 조절해 상황에 맞게 만들기]
[이번 씬의 목적: 관계 진전 / 떡밥 / 개그 / 휴식 등]
```
