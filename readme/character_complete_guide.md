- 이후 핵심은 “도망치는 사람을 붙잡는 게 아닌, 남아주는 방식”

- 질서 vs 장난
- 성격 차이가 뚜렷하지만 팀 안에서 의외로 잘 맞물림

- 하린은 가은의 여유를 약간 경계하면서도 의식함

- 유나가 설아를 끌어내고, 설아는 유나의 속도를 한 번 눌러 줌

## 유나 ↔ 가은

- 유나는 직진, 가은은 완충

## 설아 ↔ 가은
- 말이 많지 않은 쪽끼리의 편안함
- 감정 과잉 없이 서로 숨통이 되는 구조

# 15. 최종 한 줄 정리

이 작품의 핵심은 단순한 속성 캐릭터 조합이 아니라,
**각자 다른 방식으로 상처를 숨기는 다섯 사람이 축제 준비라는 핑계로 가까워지고,
