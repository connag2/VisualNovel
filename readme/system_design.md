# 시스템 설계 명세서

## 1. 호감도 및 이해도 시스템
- 변수명: 
  - 호감도: `aff_harin`, `aff_yuna`, `aff_seola`, `aff_gaeun`
  - 이해도: `und_harin`, `und_yuna`, `und_seola`, `und_gaeun`
- 초기값: 0, 증감 단위: 1~2, 최대값: 제한 없음
- 증감 조건:
  - 호감도: 칭찬, 무조건적 동의, 함께 시간 보내기 (지나치면 집착 배드엔딩 발동)
  - 이해도: 맹목적 위로 대신 적당한 거리두기, 상대의 트라우마를 자극하지 않는 배려, 시선 피해주기 (트루 엔딩 조건)
  - 공통 프롤로그에서 최소 2회 이상의 적립 기회 존재
  - 증감 단위: +1 / -1
  - 최대값: 선택의 밤 진입 전 최소 2 이상 필요 (대본 분량에 따라 결정)
- 증감 조건 (선택지, 이벤트):
  - 학생회실 심부름(하린), 동아리방 청소(유나), 도서관(설아), 옥상(가은) 등 초기 선택
  - 무심하게 챙겨주기(+1) vs 이유 캐묻기(-1) 등 마음을 향해 다가간 정도에 따라 변동
  - 단순 친밀도가 아닌 깊은 관계성의 발전 여부

## 2. 핵심 플래그
- flag_harin_secret, flag_yuna_wall, flag_seola_rumor, flag_gaeun_past
- 각 플래그의 획득 조건과 서사적 의미:
  - `flag_harin_secret`: 하린의 무너짐 앞에서 통제나 동정이 아닌 조용한 수용을 선택 (하린 돕기 이벤트)
  - `flag_yuna_wall`: 유나를 후배나 귀여운 존재가 아닌 동등한 사람으로 붙잡음 (유나 돕기 이벤트)
  - `flag_seola_rumor`: 설아를 설명시키거나 끌어내지 않고 외부 시선으로부터 먼저 보호 (설아 돕기 이벤트)
  - `flag_gaeun_past`: 가은의 거부 반응을 혐오하지 않고 강요 없이 기다려 줌 (가은 돕기 이벤트)

## 3. 루트 진입 조건
- 호감도 기반 루트 분기 로직:
  - 공통 루트 마지막 밤 직전 호감도 2 이상인 캐릭터 루트로 진입
  - 공통 루트 마지막 선택에서 해당 히로인을 향한 선택 유지 필요
- 동점 처리 우선순위:
  1. 마지막 선택의 대상
  2. 핵심 플래그 보유 여부
  3. 가장 최근 호감도 증가 대상
  4. 판정 불가 시 공통 배드엔딩 02 (엇갈린 교차로)

## 4. 엔딩 판정
- True / Normal / Bad 엔딩 조건:
  - True End: 해당 루트 진입 성공, 해당 히로인 True Flag 보유, 최종 선택에서 "고치려 하지 않고 곁에 남는 태도" 유지, 루트 내 핵심 신뢰 선택지 최소 1회 성공
  - Normal End: 호감도 조건 충족으로 루트 진입했으나 True Flag 미보유 또는 최종 선택 미달 (관계는 남지만 깊은 전환 없음)
  - Bad End: 상처를 잘못 건드림(동정, 통제, 회피, 공포 반응). 캐릭터가 가장 두려워하는 방식으로 관계가 파열됨
- 각 히로인별 엔딩 조건 매트릭스:
  - 서하린:
    - True: 닿지 않는 평행선 (애틋한 이별과 홀로서기)
    - Normal: 어색한 짝꿍 (조금 특별한 반장과 급우)
    - Bad (H1/H2/H3): 파국 (서로 상처만 남김), 닿지 않는 마음 (선 긋기), 맹목적인 의존 (집착)
  - 유나:
    - True: 사탕 발린 약속 (동등한 연인으로 진지한 시작)
    - Normal: 녹아버린 시간 (거절 후 어색한 사이)
    - Bad (Y1): 독이 든 사탕 (흑화, 일상 통제)
  - 설아:
    - True: 달빛 아래의 침묵 (영혼의 단짝)
    - Normal: 정적 속으로 (거리감 유지)
    - Bad (S1): 증발 (자퇴 후 소멸)
  - 민가은:
    - True: 노을 속의 재회 (성인이 된 후 재회하여 맺어짐)
    - Normal: 미적지근한 커피 (학창 시절 알았던 좋은 선배)
    - Bad (G1): 과거의 망령 (혐오, 투명인간 취급)

## 5. 세이브 포인트
- 권장 세이브 위치:
  - 공통 루트 마지막 밤 직전
  - 각 루트 Chapter 2 시작 직전
  - 각 루트 핵심 붕괴 장면 직전
  - 최종 엔딩 선택 직전

## 6. 회차 구조
- 1회차: 단일 히로인 루트 1개 클리어 가능
- 이후 회차: 미클리어 루트 선택 가능
- 그랜드 트루 루트 해금 조건: 모든 메인 루트 True/Normal 엔딩 확인 후 전체 True Route 해금 가능
- 회차 플레이 흐름: 전체 True Route는 주인공의 내면과 작품 전체 메시지를 회수하는 최종 루트로 작동
