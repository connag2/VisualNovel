## 1. 현재 전체 흐름 요약

### 전체 감정선 한 줄 요약
초반 1~30씬은 **축제 준비를 핑계로 다섯 사람이 점점 자연스럽게 모이고**,  
사소한 농담·답례·함께 보내는 시간들이 쌓이면서  
**“이제는 축제 준비 팀”을 넘어, 하루의 일부처럼 느껴지는 관계**로 발전하는 구간이다.

### 현재 핵심 인물 구조
- **서진**: 관찰자이자 중심 시점. 처음엔 무심하지만 점점 이 관계에 익숙해진다.
- **유나**: 활기, 돌진력, 장난기. 관계의 시작 버튼을 제일 자주 누르는 인물.
- **하린**: 단정, 책임감, 완벽주의. 질서를 만들고 팀의 틀을 잡는다.
- **설아**: 조용함, 거리감, 섬세함. 말은 적지만 한마디 한마디가 깊게 남는다.
- **가은**: 여유, 다정함, 분위기 완화. 감정 완충재이자 선배 포지션의 따뜻함.

### 현재 1~30의 큰 단계
#### 1~5
각 캐릭터의 첫인상 소개 구간.
- 1: 유나와의 아침 등굣길. 활기와 친근한 장난의 시작.
- 2: 하린의 완벽주의와 반장 성격 소개.
- 3: 설아와의 조용한 도서관 공기, 외부 소문과 미세한 상처 제시.
- 4: 가은 선배와의 옥상 대화, 편하고 부드러운 선배 포지션 구축.
- 5: 유나와 다시 이어지는 소란스러운 쉬는 시간의 활기.

#### 6~10
개인 접점이 팀 단위로 확장되는 구간.
- 종례 이후 준비실 지명.
- 다섯 사람이 축제 준비를 명목으로 한곳에 모이기 시작.
- 처음엔 어색하지만 작업과 농담이 반복되며 호흡이 생긴다.
- 아직은 큰 사건 없이, “같이 있어도 덜 불편하다”가 형성된다.

#### 11~15
관계가 가벼운 친분에서 기억에 남는 친밀감으로 넘어가는 구간.
- 반짝이, 형광펜, 피자 파티, 팀명, 사진.
- 같이 만든 말, 같이 웃은 장면, 같이 찍은 사진이 쌓인다.
- 단순히 한 공간에 모인 게 아니라 **공유 기억**이 생기기 시작한다.

#### 16~20
서로 익숙해진 느낌이 분명해지는 구간.
- 점심시간 소동, 방과 후 아지트, 하굣길, 점심 20분의 약속, 작업 효율 상승.
- “누가 먼저 부르지 않아도 모인다”는 감각이 서서히 생긴다.
- 이 시점부터는 관계가 이벤트 중심이 아니라 루틴 중심으로 변한다.

#### 21~25
정이 붙는 핵심 구간.
- 작업이 끝났는데도 쉽게 흩어지지 않음.
- 단체방, 별명, 안쪽 공기, 문을 열면 있는 사람들.
- 외부의 시선이나 짧은 타인의 말이 들어오면서,  
  이 다섯 사람의 분위기가 내부적으로 더 단단해진다.
- “준비실”보다 “안에 누가 있는지”를 먼저 떠올리게 된다.

#### 27~30
가기 아까운 관계가 되는 구간.
- 같이 고르는 사소한 것들.
- 끝나기 전에 한 번 더.
- 사서 먹는 시간.
- 헤어지기 아쉬운 길.
- 이 구간의 핵심은 사건이 아니라 **헤어지기 아쉬운 감정**이다.
- 30씬 시점에서 이미 “축제 준비 때문에 만나는 사람들”을 넘어,  
  **이제는 같이 있는 시간 자체가 중요한 사람들**이 되어 있다.

## 2. 현재 스크립트의 강점

### 잘 되는 점
1. **초반 톤이 무겁지 않다**
   - 일상, 준비, 잡담, 장난, 작은 호의가 중심이다.
   - 기준서의 “초중반은 지나치게 무겁게 내리지 않는다”는 방향과 잘 맞는다.

2. **캐릭터 구분이 비교적 명확하다**
   - 유나: 장난기와 적극성
   - 하린: 단정함과 책임감
   - 설아: 조용함과 여운
   - 가은: 다정한 여유
   - 서진: 관찰과 점진적 익숙함

3. **관계가 사건보다 루틴으로 쌓인다**
   - 준비실, 매점, 하굣길, 단체방, 공동 작업 같은 반복 공간이 좋다.
   - 이런 루틴형 장면은 정붙이기에 강하다.

4. **30씬까지의 감정선이 자연스럽다**
   - 갑자기 친해진 느낌보다, 사소한 시간들이 누적된 느낌이 난다.

5. **추가된 자산의 방향이 맞다**
   - `bgm_daily_light`
   - `bgm_group_fun`
   - `bgm_after_school_soft`
   - `cg_group_work_table`
   - `cg_store_snack_choice`
   - `cg_harin_small_smile`
   - 이런 자산들은 우정 축적 구간과 잘 맞는다.

## 3. 현재 아쉬운 점 / 지금 필요한 것

### 서사적으로 필요한 것
1. **축제 자체의 구체성**
   - 지금은 “함께 준비한다”는 감정은 좋은데,
   - **무엇을 준비하는지, 어디까지 왔는지, 축제 당일에 어떤 형태로 보일지**가 조금 더 또렷하면 좋다.
   - 2챕터 시작부터 축제의 물리적 현실감을 올릴 필요가 있다.

2. **각 캐릭터의 개인 상처 전조**
   - 아직은 일상 중심이라 좋지만,
   - 2챕터부터는 각자의 불안 요소가 아주 약하게라도 가장자리에서 보여야 한다.
   - 단, 본격 폭발은 아직 이르다.

3. **바깥 세계와의 마찰**
   - 지금까지는 내부 공기가 너무 좋다.
   - 20% 불안 빌드를 위해서는
     - 외부 시선
     - 소문
     - 압박
     - 일정 문제
     - 개인 트리거
     가 아주 조금씩 필요하다.

4. **서진의 감정 자각**
   - 현재는 “좋다”, “익숙하다”, “마음에 남는다” 단계.
   - 2챕터에서는 “이 관계가 깨지면 싫다” 수준까지 조금씩 올라가야 한다.

### 리소스적으로 필요한 것
1. **축제 시작용 CG 또는 배경감**
   - 교실/준비실의 장식이 더 진행된 느낌.
   - 복도 포스터, 안내판, 완성도 올라간 결과물.

2. **약한 불안 BGM**
   - 너무 공포스럽지 않은, 얇은 긴장용.
   - 일상을 깨지 않으면서 살짝 어긋나는 곡.

3. **생활 SFX 보강**
   - 마커, 가위, 의자, 비닐, 폰 진동 같은 생활음이 더 있으면 장면 밀도 증가.

4. **군중/축제 전야 분위기용 환경음**
   - 멀리서 들리는 준비 소음, 복도 웅성거림, 방송 같은 것.

## 4. 2챕터 시작 방향: 축제 시작

### 2챕터의 핵심 목표
2챕터는 단순히 “축제가 시작된다”가 아니라,

**1챕터에서 쌓인 관계를, 축제라는 더 큰 외부 상황 속으로 밀어 넣는 장**이어야 한다.

즉,
- 1챕터: 우리끼리 친해진다.
- 2챕터 초반: 친해진 우리를 바깥 현실이 건드리기 시작한다.

### 2챕터 시작 분위기
완전히 어두워지면 안 된다.
정답은:

**겉으로는 더 들뜨고 활기찬데, 안쪽엔 아주 얇은 금이 생기기 시작하는 분위기**

예시 감각:
- 교실은 더 화려해짐
- 사람들은 더 들뜸
- 준비는 더 바빠짐
- 다 같이 있는 시간은 더 귀해짐
- 그런데 각자 표정이나 타이밍, 말 사이사이에 어긋남이 아주 조금 보임

### 2챕터 첫 인상에 필요한 요소
1. 축제 준비가 실제로 진척되었다는 느낌
2. 모두가 더 자주 모이지만 동시에 더 피곤해진 느낌
3. 바깥 사람들의 시선이 늘어남
4. 조그만 실수도 감정에 더 남기 시작함
5. “즐겁다”와 “불안하다”가 동시에 존재하기 시작함

## 5. 점점 불안해지는 20% 설계

### 기본 원칙
- 갑자기 무너지면 안 됨
- 공포 연출처럼 가면 안 됨
- 아직은 “치료”보다 “전조” 단계
- 독자가 먼저 눈치채는 방식도 좋음
- 캐릭터 본인이 바로 자각하지 않는 불안이 더 좋음

### 불안의 종류
#### 1) 외부 불안
- 다른 학생들의 시선
- 복도에서 들리는 짧은 평가
- “저 팀 요즘 맨날 같이 다닌다”
- “쟤 좀 예민하지 않아?”
- “그거 걔가 다 한 거야?”
- 축제 준비 성과에 대한 비교

#### 2) 내부 불안
- 하린: 완성도 압박, 틀어짐에 대한 스트레스
- 설아: 타인의 시선, 소문, 자기 몸/감각 관련 예민함
- 유나: 분위기를 띄우는 역할을 놓쳤을 때의 불안
- 가은: 여유로워 보이지만 혼자 감정 삼키는 쪽
- 서진: 이 관계가 중요해진 만큼, 균열에 민감해짐

#### 3) 시간 불안
- 축제가 가까워질수록 시간이 빨라짐
- “오늘도 금방 지나갔다”
- “이 시간이 끝나면?”
- “축제 끝나고도 계속 이럴까?”
이런 감정이 서서히 들어와야 한다.

### 20% 불안 빌드 방식
#### A. 대사는 밝게, 문장은 조금 다르게
예:
- 겉으로는 웃긴 대화
- 서진 내면에서만 짧게 멈칫
- 누군가의 표정이 아주 잠깐 굳음
- 사운드가 잠깐 비거나, 말이 한 템포 늦음

#### B. 큰 사건 대신 작은 균열
- 약속 시간에 한 명이 조금 늦음
- 평소 같으면 넘길 말이 유독 마음에 남음
- 외부인이 던진 한마디가 준비실 안 공기를 잠깐 식힘
- 작업물 하나가 망가져도 감정 반응이 이전보다 큼
- 단체방 답장이 평소보다 조금 늦음

#### C. “아직 괜찮다”를 반복
아직은 다 무너지지 않는다.
오히려 중요하다.
매번 작은 균열이 생겨도,
마지막엔 다시 함께 돌아오는 식이어야
후반 치료 파트가 먹힌다.

## 6. 2챕터 초반 추천 구조

### 추천 시작 구조
#### Scene 31
- 축제 준비가 눈에 띄게 진척된 학교
- 복도와 교실이 더 바빠짐
- 우리 팀도 더 익숙하게 움직임
- 겉으로는 활기차다
- 마지막에 아주 작은 위화감 하나

#### Scene 32
- 외부인의 짧은 말 / 시선 / 비교
- 누구 하나는 별거 아닌 척 넘기지만, 서진이 그 반응을 눈치챔

#### Scene 33
- 작업 중 작은 실수
- 예전 같으면 웃고 넘겼을 텐데, 누군가 한 템포 늦게 반응
- 바로 풀리긴 하지만, 잔흔 남음

#### Scene 34
- 하굣길 or 준비실 잔류
- 다 같이 있는데도 순간적으로 조용해지는 틈
- 서진 내면에서 처음으로 “끝나고 나면 어떻게 되지?”가 스침

#### Scene 35 이후
- 불안 빌드는 계속되지만,
- 완전히 무겁게 내리기보다
- 좋은 시간과 불안한 전조가 섞여 있어야 함

## 7. 앞으로 스크립트 쓸 때 가장 중요한 주의사항

### 절대 기준
1. **새 캐릭터를 함부로 추가하지 말 것**
2. **현재 존재하는 배경, CG, 표정, 오디오 안에서 우선 구성할 것**
3. **초반~중반은 감정 축적이 핵심이므로 너무 빨리 무겁게 내리지 말 것**
4. **캐릭터별 기본 인상을 깨지 말 것**
5. **트라우마는 한 번에 폭발시키지 말고, 가장자리에서 먼저 스며들게 할 것**

### 서사 주의사항
1. **관계는 사건보다 반복으로 쌓는다**
   - 같이 걷기
   - 같이 먹기
   - 같이 정리하기
   - 같이 기다리기
   - 같이 웃기
   이런 장면이 중요하다.

2. **우정 장면은 반드시 기억 포인트를 남겨야 한다**
   - 별명
   - 말버릇
   - 같이 고른 것
   - 사진
   - 장난
   - 답례
   - 익숙한 루틴

3. **불안 장면은 아직 해설하지 말 것**
   - “사실 이건 트라우마 전조였다”처럼 설명하면 안 됨
   - 독자가 먼저 감지하게 만드는 편이 좋다.

4. **누군가의 상처를 소비형 이벤트로 쓰지 말 것**
   - 보기 좋은 충격용 금지
   - 반드시 관계와 치료로 이어져야 한다.

5. **축제는 배경이 아니라 촉매**
   - 축제 준비가 사람을 더 붙게 만들고,
   - 동시에 더 불안하게 만드는 장치가 되어야 한다.

### 연출 주의사항
1. **모션은 눈에 거슬리지 않게**
   - 말하는 캐릭터 반응은 좋지만 과하면 피로하다.
   - 자동 반응은 미세하게.
   - 반복 모션은 속도 완화 유지.

2. **캐릭터 위치/크기**
   - 무릎 아래 다리가 대화창에 살짝 가려지는 정도 유지
   - 너무 뜨거나 너무 작지 않게
   - 여러 명 장면에서 겹침 주의

3. **다른 인물 반응**
   - 여러 명 씬에서 한 명만 움직이면 화면이 죽는다.
   - 다만 모두가 크게 움직이면 피곤하다.
   - 핵심은 “듣고 있다”는 정도의 약한 반응.

4. **BGM 전환**
   - 지나치게 자주 갈지 말 것
   - 일상 → 따뜻함 → 아주 약한 불안
   이 흐름이 자연스럽게 이어져야 함

5. **CG 사용 빈도**
   - 감정 고조 / 기억 포인트 / 관계가 눈에 보이는 순간에만
   - 모든 장면에 남발 금지

### 기술 주의사항
1. **세이브 호환**
   - 앞부분 구조를 크게 바꾸면 세이브 충돌 가능성 큼
   - 가능하면 뒤에 씬을 추가하는 방식이 안전

2. **리소스명 오타 금지**
   - 없는 bgm, 없는 transform, 없는 화자 이름 금지

3. **Scene 번호 관리**
   - 현재 26은 비어 있음
   - 이후 번호를 넣을 때 의도적으로 비운 것인지 확인 필요

4. **표정 사용**
   - 기준서에 없는 표정 호출 금지
   - 감정 과잉 표정 남발 금지

5. **공백/가독성**
   - 작업 메모를 쓸 때는 장면 / 목적 / 분위기 / 감정 포인트를 띄워서 분리
   - 나중에 다시 읽기 쉽게 단락 간 공백 유지
