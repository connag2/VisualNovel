📋 [렌파이 스크립트 생성 규칙]
1. 캐릭터 및 독백 분리 원칙

주인공의 대사와 독백을 반드시 분리해서 작성할 것.

주인공 대사용: sj "대사" (예: define sj = Character('서진', ...))

주인공 독백용: th "속마음" (자동으로 괄호가 쳐지도록 what_prefix="(", what_suffix=")"가 적용된 변수 사용)

지문 및 상황 묘사: 화자 지정 없이 "내용" 형태로 작성하여 기본 내레이터가 처리하게 할 것.

2. 심리적 복선 및 호흡 연출 (가장 중요)

단순히 대사만 나열하지 말고, 기획서(story.md, characters.md)에 명시된 캐릭터의 미세한 심리적 복선(손가락 쥐기, 표정 굳음, 시선 회피 등)을 지문으로 반드시 묘사할 것.

플레이어가 감정의 변화나 멈춤을 느낄 수 있도록 중요한 지문이나 대사 중간에 텍스트 지연 태그({w=0.3}, {w=0.5})를 적극적으로 사용할 것.

3. 화면 연출 및 사운드 지시어 포함

장소가 바뀔 때는 scene과 트랜지션(with fade, with dissolve)을 사용할 것.

캐릭터가 등장/퇴장하거나 표정이 바뀔 때는 show, hide를 사용할 것 (예: show harin normal at center).

상황에 맞는 배경음악(play music)과 효과음(play sound)을 주석(#) 형태로라도 적절한 타이밍에 배치할 것.

4. 톤 앤 매너 유지

대사의 호흡은 짧고 담백하게 유지할 것.

초반부는 말랑한 학원물처럼 보이되, 그 안에 서늘한 텐션이나 방어기제가 얇게 깔려 있도록 묘사할 것.

선택지는 필요할때마다 만들고 공간이 이동할때나 시간이 이동할때 컷신이 넘어가게 해줘
